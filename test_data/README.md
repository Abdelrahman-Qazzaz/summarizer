# Local browser QA fixtures

Everything in this folder except this file is ignored by Git. Keep disposable, non-sensitive fixtures here using these names:

- `audio.flac` — short speech audio
- `video.mov` — short video with speech
- `image-large.png` and `image-small.png` — vision-chat inputs
- `youtube_urls.txt` — one URL per line

The current local fixtures can be copied from the main worktree; they are intentionally not part of commits.
